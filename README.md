# SKLN.МОРСКОЙ БОЙ 🚢

Классическая игра "Морской бой" онлайн с системой кланов, федераций, школ и рейтингов.

## 🌟 Возможности

- 🎮 Игра с ИИ и другими игроками
- 🛡️ Система кланов и федераций
- 🏫 Привязка к школам с межшкольными турнирами
- 🏆 Рейтинг игроков, кланов и федераций
- 💬 Общий чат и чаты кланов
- 📢 Система объявлений и турниров с таймерами
- 👥 Система друзей и приглашений
- ⚙️ Гибкая настройка прав ролей
- 🎨 Настраиваемый интерфейс

## 🚀 Быстрый старт

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

## ⚠️ Важное примечание

Данная версия использует localStorage для хранения данных и предназначена для демонстрации. Для production-версии необходим бэкенд с:
- Хешированием паролей (bcrypt)
- JWT-аутентификацией
- Защитой от SQL-инъекций
- HTTPS

Подробная архитектура production-версии описана в приватном репозитории.
